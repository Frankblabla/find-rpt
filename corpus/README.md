# Local research reports

Place the supplied research PDFs directly in this directory, keeping their original
`YYYYMMDD_Broker_hash.pdf` filenames. Then follow the [main README](../README.md#start-here)
to run `/find-rpt`. Reports are discovered automatically; no manifest or import step
is needed. Files without this naming pattern or a valid date are ignored.

Only this README is committed. PDFs and other files here are ignored by Git;
do not upload or redistribute the source reports.
